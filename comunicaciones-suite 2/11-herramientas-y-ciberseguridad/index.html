Herramientas y ciberseguridad

El toolkit operativo que aplica todo lo estudiado. Cada herramienta mapeada a la capa OSI sobre la que opera.

←
De dónde venimos En App 10 · Equipos físicos, se completó el recorrido teórico-conceptual del temario. Este último módulo presenta el toolkit operativo: las herramientas estándar para observar, diagnosticar y auditar redes. Cada herramienta se mapea a la capa OSI sobre la que opera, lo que cierra el hilo conductor de la suite — el modelo OSI no es solo un esquema teórico, es el mapa que organiza el trabajo práctico cotidiano en ciberseguridad.
🎯
Lo que se aborda en este módulo
  • Herramientas de diagnóstico: ping, traceroute, arp, nslookup/dig, netstat/ss.
  • Herramientas de análisis: tcpdump y Wireshark (sniffers), nmap (escáner de puertos).
  • Herramientas de auditoría: aircrack-ng (WiFi), Burp Suite y OWASP ZAP (HTTP/HTTPS).
  • Firewalls como herramienta: iptables, nftables, pfSense.
  • Mapeo final: qué herramienta usar para observar cada capa OSI.
🧰
El toolkit estándar
La caja de herramientas presentada en este módulo es el conjunto que aparece transversalmente a lo largo de la formación en ciberseguridad. No es exhaustiva: es el set mínimo para arrancar y entender qué ocurre en una red. Cada herramienta opera en una capa o función específica, y combinadas proveen visibilidad completa sobre una infraestructura.
📡
ping
Verificación básica de conectividad ICMP. Envía un mensaje Echo Request y espera el correspondiente Echo Reply. Una respuesta exitosa indica conectividad de capa 3 (IP) hasta el destino.
🗺️
traceroute / tracert
Mapeo del camino IP hasta un destino. Utiliza el campo TTL incremental: cuando un router decrementa TTL a 0, descarta el paquete y envía un mensaje ICMP Time Exceeded que delata su existencia.

El comando se llama traceroute en Linux/macOS y tracert en Windows.
🔍
arp -a
Inspección de la tabla ARP local: qué direcciones IP se han resuelto a qué MACs en el segmento. Útil para detectar ARP spoofing: una MAC duplicada o un cambio inesperado en la asociación IP-MAC suele ser un indicador de ataque.
🌐
nslookup / dig
Consultas al servicio DNS. dig (disponible en Linux/macOS) es más potente y configurable; nslookup es la herramienta clásica multiplataforma. Son indispensables para diagnosticar problemas de resolución de nombres y verificar registros DNS.
📊
netstat / ss
Visualización de conexiones TCP/UDP activas en el host local. ss es la herramienta moderna y rápida en Linux; netstat sigue disponible en la mayoría de los sistemas.

Resultan particularmente útiles para detectar backdoors — procesos no autorizados que escuchan en puertos inusuales — y para auditar las conexiones de un equipo sospechado de estar comprometido.
🦈
tcpdump y Wireshark
Analizadores de paquetes (sniffers). Son las herramientas más importantes para entender el funcionamiento real de una red.

tcpdump es la versión de línea de comandos, adecuada para entornos sin interfaz gráfica (servidores, sesiones remotas). Wireshark ofrece una interfaz gráfica con análisis profundo, filtros configurables y disectores para cientos de protocolos.

Ambas exponen lo que ocurre en la red capa por capa, byte por byte. Permiten verificar empíricamente cualquier protocolo estudiado en la suite.
🔎
nmap
Escáner de puertos y herramienta de descubrimiento de hosts. Es el estándar de facto en reconocimiento de redes. Permite identificar qué hosts están activos, qué puertos tienen abiertos, qué servicios corren tras ellos, e incluso inferir sistemas operativos.

Tiene un doble uso: tanto defensivo (auditoría interna, detección de servicios no autorizados) como ofensivo (reconocimiento previo a un ataque). Por su capacidad, en muchos entornos su uso está regulado.
📶
aircrack-ng
Suite de herramientas para auditoría de redes WiFi. Incluye utilidades para capturar handshakes WPA, ejecutar ataques de desautenticación, intentar romper claves débiles, entre otras funciones.

Requiere placas de red en modo monitor (no todas las placas comerciales lo soportan). Es la herramienta clásica para evaluar la robustez de configuraciones inalámbricas.
🕷️
Burp Suite y OWASP ZAP
Proxies de interceptación HTTP/HTTPS. Permiten posicionarse entre el navegador y el sitio web para inspeccionar, modificar y reenviar las peticiones y respuestas.

Burp Suite es comercial, con una versión Community gratuita y limitada. OWASP ZAP es la alternativa de código abierto. Ambas son indispensables para auditoría de aplicaciones web.
🛡️
iptables, nftables y pfSense
Implementaciones de firewall de uso extendido:
  • iptables — herramienta clásica de Linux, basada en el framework netfilter del kernel.
  • nftables — sucesor moderno de iptables, con la misma idea conceptual pero sintaxis renovada y mejor desempeño.
  • pfSense — distribución BSD orientada a appliances, incluye firewall, routing, VPN, IDS y otras funciones integradas. Suele desplegarse como sistema dedicado en hardware.
🎓
Cómo se conecta con todo el temario
Cada herramienta es un "ojo" sobre una capa específica del modelo OSI. Conocer qué capa observa cada una permite diagnosticar problemas metódicamente: si una conexión falla, se sube por las capas verificando cada una con la herramienta correspondiente.
