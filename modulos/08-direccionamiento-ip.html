El protocolo IP

IP (Internet Protocol, RFC 791) es el corazón de la capa de Internet. Provee el servicio de entrega de paquetes sobre el que se construye todo. Es abierto (interconecta fabricantes), independiente del medio físico y define un esquema de direccionamiento amplio y común.

Dos características clave de IP

Connectionless: no hace handshake antes de transmitir (cada paquete viaja independiente). Unreliable: no detecta ni corrige errores — eso lo hacen otros protocolos como TCP. IP solo define el datagrama, el direccionamiento, y mueve datos entre acceso a red y transporte.

El datagrama

El datagrama es el formato de paquete de IP. Las primeras 5-6 palabras de 32 bits son el header (control); el IHL indica su longitud. Campos importantes:

  • Versión: actual = 4.
  • TTL (Time To Live): se decrementa en cada salto; al llegar a 0 se descarta (evita loops infinitos).
  • Protocolo: qué se encapsula (TCP, UDP…).
  • Direcciones origen y destino (32 bits cada una).
  • Fragmentación: ocurre al pasar de un MTU mayor a uno menor.

Direcciones IP

Identifican unívocamente un punto de acceso (interfaz) a la red — un router o host multi-homed tiene varias. Son números de 32 bits en notación decimal con puntos (ej. 123.3.45.77). Se dividen en parte de RED (asignada por autoridad/ISP, usada para rutear) y parte de HOST (asignada localmente, identifica la interfaz).

Truco del primer octeto + Ampliado

Identificás la clase mirando solo el primer octeto: 1–126 = A, 128–191 = B, 192–223 = C, 224–239 = D, 240+ = E. Ojo: 127.x.x.x está reservado para loopback, por eso clase A llega solo hasta 126.

Direcciones privadas (memorizar)

10.0.0.0 – 10.255.255.255 (una clase A)
172.16.0.0 – 172.31.255.255 (16 clases B)
192.168.0.0 – 192.168.255.255 (256 clases C)
No se rutean en Internet; se usan dentro de LANs con NAT.

Notación CIDR (prefijo)

La máscara también se expresa como la cantidad de bits a 1, agregada con "/". Ejemplo: 255.255.255.0 tiene 24 bits a 1 → 128.223.254.10/24.

¡Las clases ya no importan!

En los 90 se pasó a direccionamiento classless: CIDR (los routers no asumen /8, /16, /24) y VLSM (las subredes pueden tener distinto tamaño). El esquema con clases era poco flexible y desperdiciaba direcciones. Esto se desarrolla en el Cap. 10.

IPv6

Sucesor de IPv4 que resuelve el agotamiento de direcciones. Cambios principales:

AspectoIPv4IPv6
Tamaño de dirección32 bits128 bits
NotaciónDecimal con puntosHexadecimal con ":" (8 grupos de 16 bits)
Tipos de direcciónUnicast, multicast, broadcastUnicast, multicast, anycast (sin broadcast)
HeaderMás complejoSimplificado (menor procesamiento)
Extras—Etiquetado de flujos (QoS), autenticación y privacidad
Notación IPv6 (RFC 3513)

El :: reemplaza uno o más grupos de ceros y solo puede aparecer una vez. Ej.: 1080:0:0:0:8:800:200C:417A → 1080::8:800:200C:417A. Loopback = ::1 (equivale a 127.0.0.1).
